# Matcha Sous — Growth & SEO Playbook

A prioritized plan to make the store strong for **selling** and **online presence**.
Status as of this build. ✅ = done in code · ⚙️ = needs an app/account (you set up, we wire in).

---

## 1. SEO — what's already done ✅
Both the static site and the Shopify theme ship with:
- Unique **`<title>` + meta description** per page; **canonical** URLs
- **Open Graph + Twitter** cards with the box image (rich link previews)
- **JSON‑LD structured data**: Organization, WebSite, **Product (price + availability)**, **Breadcrumb**, and **FAQ** (FAQ page)
- `sitemap.xml` + `robots.txt` (Shopify generates these automatically too)
- Semantic HTML, descriptive `alt` text, lazy‑loaded + dimensioned + compressed images, fast fonts
- Box‑accurate, keyword‑aware copy (automatic matcha mixer, hands‑free, 10 speed levels…)

**You still need to (one‑time):**
1. **Google Search Console** (search.google.com/search-console) → add `matchasous.com` → verify → submit `https://matchasous.com/sitemap.xml`.
2. **Bing Webmaster Tools** → import from GSC (2 clicks).
3. On Shopify, set each page's **"Search engine listing"** (title + description) and the product's too.

---

## 2. Content engine (the #1 organic lever) ✅ drafts ready
Single‑product stores rank by **answering matcha questions**. We've drafted 4 articles in
`content/blog/` — publish them in Shopify (**Online Store → Blog posts**), paste the body,
and copy the front‑matter title/description into the post's SEO fields.

Starter set (already written): *How to make a matcha latte*, *Matcha without a whisk*,
*Usucha vs koicha*, *How to choose matcha*.

**Cadence:** aim for ~2 posts/month. Next keyword ideas: "matcha health benefits,"
"matcha vs coffee," "how much caffeine in matcha," "iced matcha latte recipe,"
"matcha for cafés / wholesale." Each post should link to the product naturally.

## 3. Convert more visitors
- ⚙️ **Real reviews** — install **Judge.me (free)** or Loox. Adds star ratings + review
  rich snippets (real ones — keep them honest). We'll place the widget on the product + home.
- ⚙️ **Email capture + flows** — connect **Shopify Email (free)** or **Klaviyo**. Set up:
  **welcome** (with the launch offer), **abandoned cart**, **post‑purchase**. Email is
  typically 10–30% of DTC revenue. We can add the signup section to the theme.
- ✅/⚙️ **Higher order value** — a **gift set / bundle**, a starter‑matcha add‑on, or a
  **replacement‑whisk** cart upsell. We can build the UI; you create the products.
- ⚙️ **Subscriptions** — matcha refills via a Shopify subscriptions app = recurring revenue.
- ✅ **Conversion polish we can add now** — FAQ section on the product page, trust /
  secure‑checkout badges, and a **mobile sticky add‑to‑cart** bar.
- ⚙️ **Product video** — a 10–20s "whisking in 20 seconds" clip on the product page lifts
  conversion (and adds VideoObject SEO). Send a clip and we'll embed it.

---

## 4. Get found & run ads
- ⚙️ **Google Merchant Center** — connect Shopify's **Google & YouTube** channel → your
  product gets **free listings** on Google Shopping (the Product schema/feed is ready).
- ⚙️ **Analytics + pixels** — turn on **GA4**, **Meta Pixel**, **TikTok Pixel** (Shopify →
  Settings → Customer events, or the channel apps) for measurement + retargeting. Give us
  the IDs and we'll add them to the theme if you'd rather hard‑wire them.
- ⚙️ **Social** — IG/TikTok/YouTube are linked in the footer. Short "20‑second whisk" videos
  perform well; add a shoppable Instagram feed to the homepage.
- ⚙️ **Reviews/UGC + PR** — seed units to matcha/coffee creators; add an affiliate/referral app.
