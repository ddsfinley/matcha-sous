# Matcha Sous — Blog Drafts

These are ready-to-publish, SEO-optimized blog drafts for the Matcha Sous brand blog. Each `.md` file contains a YAML front-matter block (title, meta description, target keyword, handle) followed by the article body in Markdown.

## How to publish (Shopify)

For each article file:

1. In Shopify admin, go to **Online Store → Blog posts → Add blog post**.
2. **Title:** copy the `title` value from the file's front matter.
3. **Body:** paste the article body (everything *below* the closing `---` of the front matter) into the post content editor. The Markdown headings, lists, tables, and links will format correctly; if your editor doesn't render Markdown, use the rich-text/HTML toggle to clean up formatting.
4. **Search engine listing:** click **Edit website SEO** and fill in:
   - **Page title** → the `title` value.
   - **Meta description** → the `meta_description` value.
   - **URL handle** → the `handle` value, which matches the filename without `.md` (e.g. `how-to-make-a-matcha-latte`). Keeping the handle aligned to the filename preserves the intended URL slug and keyword targeting.
5. Set a featured image, assign an author/blog, and publish (or schedule).

## Notes

- Internal links point to `/products/matcha-sous` and `/pages/how-it-works`. Confirm these paths exist in your store; adjust if your product or page handles differ.
- Front matter is for your reference only — do **not** paste it into the Shopify body field.
- Articles are written to be accurate and genuinely helpful, with the product mentioned only where contextually relevant.
