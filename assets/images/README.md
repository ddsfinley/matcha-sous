## Replacing an image
Drop a new file in this folder (same name to swap in place, or a new name +
tell us to repoint). Recommended: product shots ~**1050×1400** (4:5) or the box
at ~**1600×667**, JPG ~80% quality. Phone photos are auto‑rotated on the way in.
